# ImGui Template
AML plugin ImGui template for those that wants ImGui in your AML mod.

Original ImGui repository: https://github.com/ocornut/imgui

**ocornut** is the author of ImGui, this ImGui can be updated by taking the latest source code from Dear ImGui repository and put all of them in "ocornut" folder incase when it becomes outdated.

## ✨ Features
- Functional keyboard for ImGui text input.
- Touching ImGui will only moves the imGui, not everything, so game camera movement or game controls is unaffected.
- Supported for both 32bit and 64bit game.

## 📜 Requirements
- [AML-PSDK](<https://github.com/AndroidModLoader/aml-psdk>)
