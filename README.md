# Dear ImGui Template
AML plugin ImGui template for those that wants to integrate ImGui in the mod.

Original ImGui repository: https://github.com/ocornut/imgui

**ocornut** is the author of Dear ImGui, this repository is about integrating ImGui into AML plugin. It uses RenderWare backend to render ImGui.

## Template features
- Virtual keyboard containing all letters and keys.
- Touching ImGui will only moves the imGui, not everything, so game camera movement or game controls is unaffected.

## Supported games (AML needed)
- GTA San Andreas 2.00 (32-bit)
- GTA San Andreas 2.10 (64-bit)
- GTA Vice City 1.09 (32-bit)
- GTA Vice City 1.12 (64-bit)

## Needed repository
Required to ensure that you won't get compiler error.
- [AndroidModLoader (for "mod" folder)](<https://github.com/AndroidModLoader/AndroidModLoader>)
- [AML-PSDK (for "aml-psdk" folder)](<https://github.com/AndroidModLoader/aml-psdk>)

**without these may lead you to compiler errors.**
